# Ace Watch

DevX / Ace firmware for the Waveshare ESP32-C6-Touch-AMOLED-2.06 (410 × 502 AMOLED).

## v0.1
- DevX Pulse face: time, date, battery % (Electric blue look)
- Screen off after 10 s, tap to wake
- Time is set from the computer's clock at build time (Wi-Fi time sync comes next)

## Build & flash
ESP-IDF v6.x, target `esp32c6`. In VS Code: open this folder, pick `esp32c6`, press 🔥 (Build, Flash and Monitor).
